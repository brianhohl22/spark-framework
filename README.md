# SPARK site preview

A design preview of the SPARK section planned for susd.org (Scottsdale Unified School District). Published with GitHub Pages at https://brianhohl22.github.io/spark-framework/.

- `v3/` is the current version: five static pages. Its [README](v3/README.md) explains the files, and [HANDOFF](v3/HANDOFF.md) explains how they map to the district website.
- `v2/` and the root `index.html` are earlier prototypes, kept so existing links keep working.

The preview pages ask for an access code, which the SPARK team shares separately. Pages are marked noindex, and robots.txt blocks crawlers.
